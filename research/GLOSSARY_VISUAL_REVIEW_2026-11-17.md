# 건축 용어 사전 일러스트 정리 — 2026-11-17

사용자 요청: Reference 건축 용어 사전의 내용을 일러스트와 함께 이해할 수 있도록 정리한다.

## 반영 내용

- 기존 4분류·42개 항목을 모두 유지하고 각 항목에 SVG 개념 일러스트, 짧은 뜻풀이, 그림에서 볼 부분, 일반적인 적용 대상을 배치했다.
- 실제 랜드마크의 실측 도면과 혼동하지 않도록 개념도임을 표시했다. 원본 건물 데이터·치수·신뢰도·모델링 파일·기존 랜드마크 카드는 변경하지 않았다.
- `scripts/glossary_illustrations.py`는 외부 이미지나 생성형 이미지에 의존하지 않는 벡터 개념도를 만든다. `scripts/build.py`의 `render_glossary`가 이를 사용한다. 별도 다운로드 없이 HTML 안에서 표시된다.
- `#glossary`와 `#gloss-용어ID` 링크로 접근하면 기존 사전을 펼치고 해당 위치로 이동한다. 보통 접속에서는 원래처럼 접힌 상태다. 헤더 제목·보조 설명·외부 간격은 유지했다.
- Reference의 해당 영역·CSS·툴팁 데이터만 다시 생성했다. 전체 사이트·Files·Research 페이지는 재생성하지 않았다. 후속 전체 빌드에서도 동일 렌더러가 사용된다.

## 설명을 바로잡은 항목과 근거

- **바르질:** 방어용 망루가 아닌 걸프 지역의 바람탑으로 수정했다. 나즈디 건축 설명에서도 Barjeel을 모서리 망루로 연결한 부분을 제거했다. [UN](https://www.un.org/ungifts/node/624)
- **PTFE·ETFE:** PTFE 코팅 유리섬유 원단과 ETFE 필름을 구분하고 인장막·쿠션은 각각의 적용 예로 표시했다. [막구조 공급사 Birdair](https://www.birdair.com/membrane/)
- **오픈·풀 보울:** 이 사전의 비교용 표현임을 밝히고, 분리/연속 관람석과 지붕 덮임을 별도로 설명했다. 특정 경기장을 근거 없이 유형에 배정한 예시는 일반 적용 설명으로 바꿨다. [FIFA Stadium Bowl](https://inside.fifa.com/innovation/stadium-guidelines/general-process-guidelines/design/stadium-bowl) · [Roof](https://publications.fifa.com/de/football-stadiums-guidelines/general-process-guidelines/design/roof/)
- **로샨·산호석:** 제다의 목조 돌출 창과 산호 기원의 조적 재료로 설명했다. 로샨과 Mashrabiya를 완전히 동일한 용어처럼 병기하지 않았다. [UNESCO](https://whc.unesco.org/en/list/1361) · [로샨 보존 기록](https://whc.unesco.org/document/167416)
- **아케이드·포르티코·코니스:** 반복 아치, 기둥이 받치는 현관 지붕, 돌출 상부 띠의 차이를 도해로 구분했다. [Getty 건축 용어](https://www.getty.edu/education/teachers/classroom_resources/curricula/art_architecture/downloads/arch_vocabulary.pdf) · [Getty AAT Portico](https://www.getty.edu/vow/AATFullDisplay?find=&logic=AND&note=work&subjectid=300004145)
- **반복 모델링:** 인스턴싱의 작업 편의·메모리 이점과 출력 삼각형 수를 구분했다. 실체화·출력만으로 납품 tris가 줄어든다고 설명하지 않는다. [Blender Manual](https://docs.blender.org/manual/en/latest/modeling/geometry_nodes/instances/realize_instances.html)
- 그 외 과도한 일반화·특정 셰이더 필수 지시·임의 LOD 작업 지시를 간단한 개념 설명으로 정리했다. 기존 이름이 바뀐 경우 필요한 별칭은 툴팁 데이터에 남겼다.

## 검증

- 42개 SVG XML 파싱·고유 ID·그림과 용어 대응·렌더러 출력 일치를 확인했다.
- Headless Chrome에서 데스크톱 1366px, 실제 문서 폭 390px 모바일, 다크 테마를 렌더링하고 시각 검토했다. 사전의 42개 그림, 가로 넘침 없음, 그림 글자 잘림 없음, 카드 내용 넘침 없음, 접기·다시 펼치기와 헤더 위치 불변을 확인했다.
- 전체 개념도 검토 시 중정 위를 막아 보이던 면을 제거해 열린 공간과 유리 지붕의 아트리움을 구분하고, 무카르나스의 셀 깊이와 비계 발판을 보완했다.
- 기존 랜드마크 카드 HTML·사전 헤더가 그대로임을 바이트 비교했다. Python 컴파일과 `git diff --check`를 통과했다.
- 검토용 캡처와 임시 파일은 납품·공개 산출물에 추가하지 않았다. 공개 배포는 수행하지 않았다.
