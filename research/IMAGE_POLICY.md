# Research 이미지 운영 기준

2026-09-28 이미지 추가 요청에 적용한 기준. 기존 자료 수집 규칙은 루트 AGENTS.md를 따른다.
아래는 이번 웹 이미지 운영 방식이며, 기존 방법론에 없는 최소 해상도·필수 각도·필수 장수를 새 납품 요건으로 정한 것이 아니다.

## 선택과 표시

- 대상의 이름·지역·출처 페이지를 함께 확인한다. 검색 결과 이미지의 자동 설명만으로 건물을 확정하지 않는다.
- 대표 이미지는 실루엣과 외관을 비교할 수 있는 실제 사진을 우선한다. 내부·행사·로고 사진은 대표로 사용하지 않는다.
- 전체 형태가 잘 보이는 자료를 우선하되, 가림이나 원본 프레임의 잘림이 있으면 설명에 남긴다. 다른 각도가 판단에 도움을 주는 경우 상세 패널에 보조 이미지를 추가한다.
- 렌더링은 실제 사진과 구분하여 카드와 상세 정보에 `설계 렌더링`을 표시한다. 촬영일이 불명확한 사진은 일반 `외관 사진`으로 분류하고 상세 정보에 `촬영일 미확인`을 남긴다. 촬영일 미확인만을 이유로 `기록 사진` 배지를 붙이지 않는다. 야간 조명, 주변의 다른 건물도 필요한 경우 설명한다.
- 카드 썸네일은 기존 4:3 영역을 `object-fit: cover`로 여백 없이 채운다. 2026-09-28 사용자 승인에 따라 전체 표시 방식에서 변경했다. 이미지별 `thumbnail_position`으로 크롭 위치를 지정하고, 타워 상부·특징적인 외형이 남도록 확인한다.
- 상세 패널은 `object-fit: contain`으로 원본 비율과 전체 프레임을 유지한다. 파일 자체는 크롭하지 않으며, 썸네일의 잘린 부분은 상세 패널에서 확인한다.
- 카드 이미지에서도 상세 패널을 열 수 있다. 상세 패널에는 이미지·설명·출처를 함께 표시하며, 이미지를 누르면 같은 화면의 라이트박스에서 크게 본다. ×·Esc·사진 바깥 클릭으로 닫으면 상세 패널의 스크롤 위치와 사진 버튼 초점을 유지한다. 여러 장은 이전·다음 버튼 또는 좌우 방향키로 이동하며, 한 장이면 이동 버튼을 숨긴다.

## 기록과 검증

- 후보 ID별 이미지 목록을 도시별 `phase1-king-fahd-road/images.json`, `phase1-jeddah/images.json`에 기록한다. 첫 이미지가 대표 이미지다. 원본 URL, 출처 페이지, 촬영·제작자, 시점, 사용 조건, 가공 내역, 확인일, 파일 해시를 보존한다.
- 촬영일·제작자를 모르면 미확인으로 적는다. 파일 업로드 날짜나 건축 연도를 촬영일로 바꾸지 않는다. 보고서·기사 날짜는 촬영일과 구분한다.
- 공식 사이트에 공개되어 있다는 사실만으로 자유 이용을 의미하지 않는다. Commons의 저작자·라이선스는 이미지별로 표시하고, 명시적 이용 조건을 찾지 못한 자료는 `재사용 조건 미확인`으로 표시한다.
- 사진 추가는 곧 최신 외관·좌표·높이·경계 검증 완료를 뜻하지 않는다. 기존 미확인 사항과 추천·선정 상태를 자동으로 변경하지 않는다.
- 현재 파일은 로컬 검토용으로 추가했다. 공개 배포 시에는 각 이미지의 사용 조건을 기준으로 허가·대체 여부를 확인한다.

## 이번 Riyadh 반영

- 후보 27건, 이미지 33개. 대표 이미지는 외관 사진 25건, 렌더링 2건(SAB, RAFAL Residence)이다.
- Elegance Tower는 자산평가 보고서 15쪽의 실제 사진 2개를 사용했다. 보고서의 재배포 제한을 이미지별 사용 조건에 명시했다.
- SAB 행사 사진, RAFAL의 다른 단지로 보이는 이미지, 부처 로고, Digital City의 행사 프로젝션 이미지는 대표에서 제외했다.
- DAMAC 사진의 오른쪽 원통형 건물은 Hilton이며, Hilton 사진 왼쪽 두 동은 DAMAC이다. 각 이미지 설명에 구분을 남겼다.
- Burj Rafal(2014), Riyadh TV Tower(2008)의 자료를 최신 외관으로 표기하지 않았다. King Faisal Foundation과 Olaya Towers는 사용자 제공 이미지로 교체하고 원출처·촬영일 미확인으로 기록했다.

## Jeddah 추가 반영

- 후보 27건(건축물 14·조형물 13)에 외관 사진 29개를 연결했다. Al-Shafii Mosque의 미나레트 상세와 Bicycle Sculpture의 이전 관련 전경은 보조 사진이다.
- 건축물은 설계사·기관·전문 자료를 우선했다. Al Jawharah의 실내 이미지, Headquarters Business Park의 공사 중 사진은 대표에서 제외했다.
- Circular Mass, The Illusion of a Second Cube, Flexibility of Balance, The Bird, Oval with Points는 Jeddah Historic District 공식 페이지의 작품별 사진을 사용했다.
- Bicycle의 이전 전 형태 사진과 2022년 이전 관련 전경을 구분했다. Cosmos·Seagull·Crazy Speed도 게시 시점을 촬영일이나 최신 위치 확인으로 바꾸지 않았다.
- Al-Ruwais Mosque는 적갈색 외장 시기의 사진이다. 이후 도장·개조 상태를 입증하는 사진으로 취급하지 않는다. Khuzam Palace는 별도 레퍼런스 대문과 혼동하지 않도록 본체 입구 사진을 사용했다.
- Globe Roundabout은 Tahir mq의 2017-03-25 사진(CC BY-SA 4.0)이다. 나머지 사진의 재사용 허가 미확인 및 Mosqpedia의 원저작권 확인 필요 사항은 상세 패널에 기록했다.

## 변경 후 점검

- 대표 이미지와 카드 이름의 대응, 출처 링크와 라이선스, 파일 존재·크기, 렌더링 표시를 확인한다.
- 데스크톱·좁은 화면에서 이미지 잘림, 카드 높이 변동, 가로 넘침, 상세 패널 열기·닫기와 초점 복귀를 확인한다.
- 검색·도시별 선정 상태 필터는 이미지 유무와 무관하게 기존 후보 데이터를 기준으로 동작해야 한다.

## Khuzam Palace 썸네일 분리 (2026-09-29)

사용자 요청으로 J14의 카드 썸네일만 제공받은 궁전 대문 사진으로 교체했다. `thumbnail_only: true`인 사진은 상세 갤러리에서 제외하며, 기존 궁전 본체 사진과 출처는 상세 정보에 유지한다. 모델 범위와 중복 확인 상태는 변경하지 않는다.
